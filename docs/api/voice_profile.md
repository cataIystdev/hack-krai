# Handoff: POST /api/v1/profile/voice

## Статус

- Endpoint: `POST /api/v1/profile/voice`
- Статус: mock-safe, shape frozen
- Используется: voice screen, vibe passport screen
- Формат запроса: `multipart/form-data`, поле `audio`
- Авторизация: JWT Bearer Token

---

## Описание

Принимает аудиозапись голоса пользователя, выполняет полный
AI-пайплайн профилирования и возвращает screenshot-ready ответ
для рендеринга vibe passport на фронтенде.

### Пайплайн обработки

1. Сохранение аудио в MinIO
2. Распознавание речи через STT (Vosk-server)
3. Извлечение осей vibe-профиля через LLM
4. Генерация эмбеддинга вектора
5. Upsert вектора в Qdrant (коллекция user_vibes)
6. Обновление vibe_vector_id в PostgreSQL
7. Генерация заголовка vibe-паспорта
8. Controlled demo latency (mock-режим)

---

## Пример запроса

```bash
curl -X POST https://api.kudytudy.ru/api/v1/profile/voice \
  -H "Authorization: Bearer <token>" \
  -F "audio=@voice.mp3"
```

## Описание полей ответа

| Поле                        | Тип      | Описание                              |
| --------------------------- | -------- | ------------------------------------- |
| `transcription`             | string   | Распознанный текст из аудио           |
| `axes`                      | object   | Оси vibe-профиля                      |
| `axes.stress_level`         | float    | Уровень стресса (0.0-1.0)             |
| `axes.solitude_vs_social`   | float    | Уединение vs компания (-1.0 to 1.0)   |
| `axes.relax_vs_adrenaline`  | float    | Релакс vs адреналин (-1.0 to 1.0)     |
| `axes.gastro_vs_nature`     | float    | Гастрономия vs природа (-1.0 to 1.0)  |
| `axes.culture_vs_adventure` | float    | Культура vs приключения (-1.0 to 1.0) |
| `extracted_tags`            | string[] | 3-8 семантических тегов               |
| `vibe_summary`              | string   | Краткое резюме на русском             |
| `vibe_passport_title`       | string   | Заголовок vibe-паспорта для экрана    |
| `vector_id`                 | string   | UUID вектора в Qdrant                 |
| `processing_time_ms`        | int      | Время обработки в миллисекундах       |

---

## Описание осей

- `stress_level`: 0.0 -- спокоен и расслаблен, 1.0 -- очень устал, нужна перезарядка
- `solitude_vs_social`: -1.0 -- полное уединение, 1.0 -- шумная компания
- `relax_vs_adrenaline`: -1.0 -- релакс, спа, пляж, 1.0 -- экстрим, адреналин
- `gastro_vs_nature`: -1.0 -- гастрономия, вино, рестораны, 1.0 -- природа, лес, горы
- `culture_vs_adventure`: -1.0 -- музеи, история, 1.0 -- походы, исследование

## Возможные заголовки vibe-паспорта

Генерируются автоматически на основе доминирующей оси:

| Условие                     | Заголовок                       |
| --------------------------- | ------------------------------- |
| gastro_vs_nature < -0.3     | Гастрономический путешественник |
| culture_vs_adventure > 0.3  | Искатель приключений            |
| culture_vs_adventure < -0.3 | Культурный исследователь        |
| relax_vs_adrenaline < -0.3  | Ценитель спокойствия            |
| relax_vs_adrenaline > 0.3   | Адреналиновый турист            |
| solitude_vs_social < -0.3   | Созерцатель тишины              |
| solitude_vs_social > 0.3    | Душа компании                   |
| нет доминанты               | Исследователь Кубани            |

## Ошибки

| HTTP-код | Причина                                  |
| -------- | ---------------------------------------- |
| 400      | Аудиофайл не предоставлен (поле `audio`) |
| 401      | Не удалось извлечь user_id из токена     |
| 500      | Аудио не распознано или содержит тишину  |
| 500      | Ошибка STT / LLM / Embeddings / Qdrant   |

## Известные ограничения

- В mock-режиме (AI_API_KEY пуст) ответ детерминированный
- Mock latency: 2000ms по умолчанию (настраивается через DEMO_LATENCY_MS)
- Фронтенд не может отличить mock от real -- это by design
